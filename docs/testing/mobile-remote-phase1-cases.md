- 文件夹具用 case-owned workspace；准备中文/空格路径、同路径不同identity的独立Host、hidden/symlink/大文件。禁止触碰真实用户Downloads或生产数据库；原生验收使用测试APK/data目录并清理自身产物。
- 终态/失败/pending通过真实runtime协议与case-local provider fixture生成，使用 `E2E_MOBILE_PHASE1_*` marker。搜索/文件UI动作不触发provider；若播种依赖模型，区分setup请求与action阶段零新增请求，禁止直接改UI store伪造成功。
- timing：普通搜索/浏览用 fast-text/no-provider；pending/并发用 controlled-stream；ACK丢失/断线用 fault-stream并记录 syntheticReason。测试屏障控制时序，不用固定sleep掩盖同步问题。
- artifacts：UI截图/录像、backend/workspace/请求代际、runtime事件与命令计数、feed/outbox/read记录、HTTP/ACL结果、文件hash/byte数、构建号/设备API。记录全部脱敏；不保存凭据或模型私密正文。
