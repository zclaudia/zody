# Zody 0.1.0 Preview

Zody 0.1.0 is the first public preview. It includes the Zody desktop application, a self-contained `zody` CLI with optional Web mode, and the Android remote-control app.

macOS and Windows desktop installers are unsigned in this preview. Android is signed with the dedicated release key. Review the included `THIRD-PARTY-NOTICES.md` and verify downloads with `SHA256SUMS.txt` before use.

The CLI/Web archives include their Node runtime and target-native tools. No separately installed Node.js or pnpm is required.
