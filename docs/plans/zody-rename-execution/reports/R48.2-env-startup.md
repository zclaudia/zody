## 6. blocked 登记与放行条件

### 6.1 darwin-arm64 · 远端 ×4 —— BLOCKED

- 原因：本机无可用 SSH publickey 目标。实测 `ssh -o BatchMode=yes -o StrictHostKeyChecking=accept-new -o ConnectTimeout=5 127.0.0.1 'echo SSH_OK'` → `zhvala@127.0.0.1: Permission denied (publickey)`。
- 影响：产品真实远端连接（`packages/server/src/remote/connect.ts` 的 SSH 后端）未能在 darwin 目标上实测；远端 env 键集合 `REMOTE_RUNTIME_ENV_KEYS`（`connect.ts:58-71`：`ZODY_ENV`/`ZODY_BASE_URL`/`ZODY_ENDPOINT_ORIGIN`/`ZODY_TEST_BASE_URL`/`ZODY_PRODUCTION_BASE_URL` 等）只做了代码读取与纯函数测试引用，没有真实远端进程证据。
- 放行条件：由 R48.1-E 提供隔离 SSH 目标与 single-flight 锁后，用同一 harness（`run-remote.mjs` 的容器分支替换为 SSH exec）复跑 4 组合，并在远端进程上读 `/proc`/`ps` 环境。
- 说明：本单元未用容器目标冒充 darwin 远端；linux 容器结果单独计在 §3.3。

### 6.2 darwin-arm64 · 子进程 ×4 —— BLOCKED（Electron 段）

- 原因：`dev:desktop:test` 在 `dev:runtime` 的 tsup 阶段失败：`NarrowResourceError: enabled darwin/arm64 CUA build is missing cua-narrow manifest: output/cua-app-icon/controller-prepared/manifest.json`；`pre-dev` 期间 native `macos-window-bounds` x86_64 链接失败。与 `R48.0-baseline.md:113` 同因，属 R60/narrow4 冻结输入缺口。
- 已取得：launcher → pnpm/node 子进程的真实 env 继承（§3.2 表）；未取得：Electron 主进程 → host → agent 段的真实 env。
- 放行条件：R60 提供 cua-narrow manifest 与可用的 macos-window-bounds 构建输入后复跑 4 组合，采样 `Electron.app/Contents/MacOS/Electron` 及其 host 子进程环境。

### 6.3 linux-arm64 · 子进程 ×4 —— BLOCKED

- 原因：候选产物集中没有 Linux desktop 构建（`candidate-artifacts/desktop-out`、`desktop-bundled-agents` 均为 darwin，且 R48.0 记录 desktop 目标 exit 1）；容器内无法启动 Electron/host 链。
- 放行条件：产出 Linux desktop 目标（R48.2-C/后续构建范围）后复跑。

### 7.1 断言与合同冲突（需主控裁决）
