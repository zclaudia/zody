# R43 远端发布与回滚演练清单

本文件只描述经批准的发布流程，不授权连接或修改真实远端。本次开发测试只使用隔离本地目标和合成数据。

1. 清点目标、操作系统/架构、现运行产品版本、可恢复制品和引用该目标的所有桌面/自动部署进程；备份并验证完整旧组合可恢复，不输出凭据。
2. 暂停旧版应用与所有旧自动部署者，并确认它们不再能写目标。锁只能协调遵守同一锁协议的参与者；同进程 SSH single-flight 不阻止其他进程或不遵守锁的旧部署者。
3. 对一个隔离目标演练完整新组合同步部署；持锁后重新读取版本、manifest 和 SHA；验证实际启动实例的 hello generation 和产品版本。校验 marker 或 `--version` 仅用于部署决策，不作为业务准入。
4. 按目标逐一部署并验证，任何失败、取消、版本/代际不符或资源清理失败均保持业务关闭；不要依赖 `skipDeploy` 跳过真实运行握手。确认连接、进程与锁释放，再处理下一目标。
5. 若失败，停止所有新旧自动部署者，恢复经校验的完整旧组合并逐目标验证；保持目标关闭直到恢复一致。禁止混合版本发布或用空 marker 覆盖失败状态。
6. 收集目标状态、制品摘要、运行 hello、测试结果和清理记录；真实旧/新双方、平台与正式部署证据由后续 R48/平台验收负责。
