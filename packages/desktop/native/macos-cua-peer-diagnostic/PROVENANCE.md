# Source provenance

This directory is a first-party Zody implementation authored for the R10-N diagnostic. It contains no
copied system library, no third-party source code, no private key and no certificate. Apple SDK
headers (Foundation, Security, Darwin, CommonCrypto, libbsm) are used as public interfaces only.

License: Apache-2.0. The complete license text is in `LICENSE`. The build script records SHA-256 for
`README.md`, `PROVENANCE.md`, `LICENSE` and every source file in the build manifest.
