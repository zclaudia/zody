# Fork 独立品牌图标提案

## 目标与范围

为基于 ZCode 独立迭代的项目设计新的应用图标。当前尚未确定独立品牌名，采用无文字符号。初轮设计提案 PNG 保存在 `output/brand/`。用户已选定缩小主体后的第一版，并授权替换 Desktop 与 Android 应用图标；接入规则见 [应用图标接入](fork-app-icon-integration.md)。

## 设计规则

- 主题为“分叉、向前”：抽象分支与方向性结合，表达从共同基座独立演进。
- 使用石墨黑底和薄荷青主体，保持开发工具的沉稳、清晰与辨识度。
- 单一主体、粗线条、少细节；在小尺寸下保留清晰轮廓。
- 不包含品牌文字、口号或上游 Z 标志；不依赖细微光效表达主体。
- 圆角应用图标容器，容器外透明，主体留出充分安全边距。

## 第二轮候选方向

- `02-fold.png`：折叠代码；瓷白底与钴蓝双折角，表达代码与精确构建。
- `03-core.png`：工作台核心；墨蓝底与琥珀橙三段几何，表达模块协作与统一工作台。
- `04-ember.png`：灵感火种；暖白底与橙金双色曲线，表达创造与生长。
- 三款均为无文字、独立轮廓的新候选，保留第一版供比较。各自完整提示词保存在同名 `-prompt.txt` 中。
- 浅底的 02 与 04 使用完整不透明底色，避免生成透明抠图造成的外缘杂点；本轮用于造型和配色选择，正式接入时再统一平台遮罩与透明边缘。

## 选定方向与比例调整

用户选定第一版“分叉向前”。以 `fork-icon-v1.png` 为输入，仅将薄荷青分支箭头的宽、高等比缩放为原来的 85%，中心位置保持不变；底板尺寸、圆角、配色、画布和外部透明区域保持原样。输出 `fork-icon-v1-smaller-15.png`，原图保留。此轮只调整设计资产，不修改应用入口。

## 原始资产记录

内置 imagegen 编辑按 85% 的目标比例进行多轮校准。最终生成图为近似比例调整，薄荷青主体的像素包围盒相对原版宽度缩小约 16.4%、高度缩小约 17.6%；不将生成式编辑视为像素级精确变换。

本提案由 `output/brand/fork-icon-v1.png` 保存，生成提示词由同目录 `prompt.txt` 保存。现有 Desktop、Web 图标入口继续使用各自现有资源。本轮不修改状态、服务、协议或运行时接口。

## 验收

- 交付可打开的正方形 PNG，检查透明通道和图像尺寸。
- 视觉检查分支符号、主体边距与轮廓清晰度。
- 仓库基线检查通过；按项目要求执行 typecheck 与 lint，记录真实结果。
- 后续正式接入时另行明确多平台尺寸、ICO/ICNS 与 favicon 验收，不把本轮概念稿视为已集成资源。
